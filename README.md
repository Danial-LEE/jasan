# 자산관리 계기판

『1억부터는 포트폴리오다』(신환종)의 역할 중심 자산배분을 참고한 개인용 리밸런싱·수익률 분석 앱입니다.

- 내 설정(바꾸고 싶은 항목만): `settings.js` — 처음 한 번 올리고 직접 고침
- 구글 드라이브 저장 설정: `config.js` — 처음 한 번 올리고 직접 고침
- 앱 기본 설정: `defaults.js` — 업데이트 때 덮어쓰므로 고치지 않음
- 업데이트: 받은 `깃허브_업로드` 폴더 안의 파일을 모두 덮어 올리면 됨
- 설치와 사용법: `설치안내.md`

자산 자료는 이 저장소가 아니라 각 사용자의 기기와 구글 드라이브에만 저장됩니다.
